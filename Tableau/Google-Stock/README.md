# Google Stock Analysis – Tableau Dashboard

An interactive Tableau dashboard created to analyze Google (GOOGL) stock performance and identify price trends and market patterns.

## 🛠️ Tools Used

- Tableau Public
- Data Visualization
- Calculated Fields
- Filters
- Parameters
- KPI Analysis
- Interactive Dashboard

## 🎯 Project Objective

The objective of this project is to analyze Google's historical stock data and visualize important stock performance indicators, trends, and patterns through an interactive Tableau dashboard.

## 📊 Dashboard Highlights

- Stock price trend
- Opening and closing price analysis
- High and low price analysis
- Trading volume analysis
- KPI indicators
- Interactive date filters
- Historical performance analysis
