# Google Stock Analysis – Tableau Dashboard

## 📊 Project Overview

The **Google Stock Analysis Dashboard** is an interactive Tableau project developed to analyze Google (GOOGL) stock performance and explore historical price trends and market patterns.

The dashboard presents stock data through interactive visualizations, allowing users to explore price movements and analyze Google stock performance over time.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze Google (GOOGL) stock performance
- Explore historical stock price trends
- Understand price movements over time
- Identify patterns in stock performance
- Create an interactive financial dashboard
- Practice data visualization using Tableau

## 🔄 Project Workflow

The project followed a structured data visualization workflow:

**Stock Data → Data Preparation → Data Analysis → Visualization → Dashboard Development → Interactive Analysis**

### 1. Data Preparation

- Imported the Google stock dataset into Tableau
- Reviewed the available stock-related fields
- Prepared the data for visualization

### 2. Data Analysis

- Analyzed historical stock prices
- Examined price movements over time
- Explored different stock-related measures

### 3. Visualization

- Created charts to represent stock trends
- Used time-based visualizations for historical analysis
- Added relevant filters and interactive elements

### 4. Dashboard Development

- Combined multiple visualizations into a single dashboard
- Designed the dashboard for clear data interpretation
- Added interactive features for exploring different time periods
