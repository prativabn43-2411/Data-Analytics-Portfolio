# Translogix Analytics

An interactive Tableau dashboard designed to analyze logistics and delivery performance using data visualization and business intelligence techniques.

## Dashboard Highlights

- Delivery Delay Rate
- Delay Rate by Route
- Delay Rate by Driver Experience
- Monthly Delay Trend
- Current Month vs Previous Month Delay Rate
- KPI Cards
- Interactive Filters

## Tools Used

- Tableau Public
- Calculated Fields
- Parameters
- Filters
- KPI Analysis
- Data Visualization

## Key Objective

The objective of this project is to analyze delivery performance, identify factors contributing to delays, and provide actionable insights through an interactive Tableau dashboard.
