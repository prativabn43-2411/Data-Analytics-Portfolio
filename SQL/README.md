# 🗄️ SQL Projects & Practice

Welcome to my **SQL Projects & Practice** portfolio.

This folder contains my hands-on SQL learning and practice work, focused on developing strong skills in **data querying, data manipulation, relational database analysis, and business-oriented problem solving**.

Through these exercises and projects, I am building the SQL foundation required for a **Data Analyst** role.

---

## 🎯 What I Do with SQL

I use SQL to explore, transform, filter, aggregate, and analyze structured data.

My practice focuses on writing queries that answer real-world business questions and extracting meaningful insights from relational databases.

### 🔹 SQL Fundamentals

I practice the core SQL concepts required for working with databases:

* `SELECT`
* `WHERE`
* `ORDER BY`
* `DISTINCT`
* `LIMIT`
* Filtering and sorting data
* Working with different data types

### 🔹 Aggregate Functions

I use aggregate functions to summarize and analyze data:

* `COUNT()`
* `SUM()`
* `AVG()`
* `MIN()`
* `MAX()`

I also practice combining aggregate functions with:

* `GROUP BY`
* `HAVING`

### 🔹 SQL Joins

I practice combining information from multiple related tables using:

* `INNER JOIN`
* `LEFT JOIN`
* `RIGHT JOIN`
* Multi-table joins

Joins help me analyze relationships between different datasets and tables.

### 🔹 Subqueries

I practice using subqueries to solve multi-step analytical problems, including:

* Filtering based on another query
* Comparing values with aggregated results
* Finding records above or below an average
* Using subqueries with `IN`, `EXISTS`, and comparison operators

### 🔹 Common Table Expressions (CTEs)

I use **CTEs** to break complex queries into smaller and more readable steps.

I practice CTEs for:

* Multi-step analysis
* Aggregation
* Ranking and comparison
* Joining intermediate results
* Improving query readability

### 🔹 CASE Statements

I use `CASE` statements to create conditional logic and categorize data.

Examples include:

* Creating business categories
* Classifying values
* Creating performance groups
* Applying conditional calculations

### 🔹 Constraints & Database Concepts

I am also practicing database fundamentals such as:

* Primary Keys
* Foreign Keys
* Unique Constraints
* NOT NULL
* CHECK Constraints
* Data relationships
* Table structure
