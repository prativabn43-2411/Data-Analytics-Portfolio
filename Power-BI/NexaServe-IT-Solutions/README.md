# NexaServe IT Solutions Dashboard

An interactive Power BI dashboard developed to analyze business performance, employee information, revenue, customer satisfaction, and project-related metrics for NexaServe IT Solutions.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization

## Project Objective

To transform business data into an interactive dashboard that helps monitor key performance indicators and identify important business trends.

## Key KPIs

- Total Employees
- Total Revenue
- Renewal Rate
- Average Satisfaction Score

## Dashboard Features

- KPI Cards
- Interactive Slicers
- Revenue Analysis
- Employee Analysis
- Customer Satisfaction Analysis
- Renewal Rate Analysis
- Interactive Visualizations
