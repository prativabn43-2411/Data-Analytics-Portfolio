# Titanic Survival Analysis – Power BI Dashboard

## 📊 Project Overview

The **Titanic Survival Analysis Dashboard** is an interactive Power BI project developed to analyze passenger information and explore the factors associated with survival in the Titanic dataset.

The dashboard transforms passenger-level data into interactive visualizations, making it easier to explore survival patterns across different passenger characteristics.

This project demonstrates practical skills in **Power BI, Power Query, DAX, data modeling, and data visualization**.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze passenger survival patterns
- Explore survival across different passenger groups
- Compare survival based on passenger characteristics
- Identify relationships between passenger attributes and survival
- Create an interactive and user-friendly dashboard
- Present data-driven insights through visualizations

---

## 🚢 Dataset

The project uses the **Titanic passenger dataset**, which contains information about passengers aboard the RMS Titanic.

The dataset includes passenger-related attributes that can be used to analyze survival patterns, such as:

- Passenger Class
- Gender
- Age
- Fare
- Number of Siblings/Spouses
- Number of Parents/Children
- Embarkation information
- Survival status

## 🔄 Project Workflow

The project followed a structured data analytics workflow:

**Raw Data → Data Cleaning → Data Transformation → Data Modeling → DAX Calculations → Dashboard Development → Analysis**

### 1. Data Preparation

- Imported the Titanic dataset into Power BI
- Reviewed the available fields and data types
- Identified the variables required for survival analysis

### 2. Data Cleaning & Transformation

- Cleaned and prepared the dataset using Power Query
- Handled data types and formatting
- Prepared the data for analysis and visualization

### 3. Data Modeling

- Organized the dataset for reporting
- Established the required data structure
- Prepared fields and measures for dashboard analysis

### 4. DAX Calculations

- Created analytical measures where required
- Developed calculations to support dashboard KPIs
- Used DAX measures within visualizations

### 5. Dashboard Development

- Designed an interactive dashboard
- Added KPI cards and charts
- Used slicers and filters for data exploration
- Organized visuals to communicate the analysis clearly
