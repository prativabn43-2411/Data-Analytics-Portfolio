# Titanic Survival Analysis Dashboard

An interactive Power BI dashboard analyzing the Titanic dataset to identify the factors associated with passenger survival.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization

## Project Objective

To analyze Titanic passenger data and understand survival patterns based on factors such as passenger class, gender, age, and other passenger characteristics.

## Key KPIs

- Total Passengers
- Survived Passengers
- Survival Rate
- Passenger Count by Class

## Dashboard Features

- Survival Rate Analysis
- Survival by Gender
- Survival by Passenger Class
- Age Analysis
- Passenger Class Distribution
- Interactive Filters and Slicers
- KPI Cards

## Key Business Questions

- What was the overall survival rate?
- Which passenger class had the highest survival rate?
- How did survival differ between male and female passengers?
- How did age affect survival?
- Which passenger groups had better survival outcomes?
