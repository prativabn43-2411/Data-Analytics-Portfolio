# Retail Data Analysis Dashboard

An interactive Power BI dashboard developed to analyze retail sales performance, customer behavior, product performance, and business trends.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization

## Project Objective

To analyze retail data and create an interactive dashboard that provides meaningful insights into sales, profit, customers, products, and overall business performance.

## Key Features

- Total Sales KPI
- Total Profit KPI
- Total Orders
- Customer Analysis
- Product Performance
- Sales Trend Analysis
- Category-wise Analysis
- Regional Analysis
- Interactive Slicers
