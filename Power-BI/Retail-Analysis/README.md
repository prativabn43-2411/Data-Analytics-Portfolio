# Retail Data Analysis – Power BI Dashboard

## 📊 Project Overview

The **Retail Data Analysis Dashboard** is an interactive Power BI project developed to analyze retail business performance from multiple perspectives.

The project focuses on **customer insights, order performance, product performance, and supplier analysis**, transforming retail data into interactive dashboards that make business information easier to explore and understand.

This project demonstrates the practical application of **Power BI, Power Query, DAX, data modeling, and data visualization** in a retail analytics environment.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze customer-related information and behavior
- Monitor order performance and business activity
- Analyze product performance
- Understand supplier-related information
- Identify patterns and trends in retail data
- Build interactive and user-friendly dashboards
- Present business data through meaningful visualizations

## 🔄 Project Workflow

The project followed a structured data analytics workflow:

**Raw Data → Data Cleaning → Data Transformation → Data Modeling → DAX Calculations → Dashboard Development → Analysis**

### 1. Data Preparation

- Imported retail data into Power BI
- Reviewed the available tables and fields
- Identified relevant data required for analysis

### 2. Data Cleaning & Transformation

- Cleaned and prepared the data using Power Query
- Transformed data into an analysis-ready format
- Standardized relevant fields and values where required

### 3. Data Modeling

- Created relationships between relevant tables
- Organized the data model for analysis
- Prepared the model for dashboard reporting

### 4. DAX Calculations

- Created measures for analytical requirements
- Developed calculations to support KPIs
- Used DAX measures within dashboard visualizations

### 5. Dashboard Development

- Created three interactive dashboard pages
- Added KPI cards and analytical charts
- Added slicers and filters
- Organized visuals for clear and effective reporting
