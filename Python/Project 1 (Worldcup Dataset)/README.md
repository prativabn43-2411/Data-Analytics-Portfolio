# 🏏 Cricket World Cup Data Analysis

## 📌 Project Overview

This project explores Cricket World Cup match data using Python to identify patterns in team performance, World Cup titles, match scores, winning margins, and host-country match counts.

The project uses data analysis and visualization techniques to transform raw cricket data into meaningful insights.

## 🎯 Project Objectives

- Analyze the top 10 teams by match wins.
- Explore World Cup titles won by different teams.
- Examine the number of matches recorded across seasons.
- Compare World Cup victories by runs and wickets.
- Understand the distribution of match scores.
- Identify the top 10 teams by average recorded score.
- Rank the top 10 hosts by recorded match count.
- Explore the relationship between opposing teams' scores.

## 🛠️ Tools & Technologies

- **Python** – Data analysis and programming
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical data visualization
- **Jupyter Notebook** – Interactive coding and analysis

## 📊 Key Analysis & Visualizations

1. **Top 10 Teams by Match Wins** – Compares teams based on recorded match victories.
2. **World Cup Titles by Team** – Examines the distribution of tournament titles.
3. **Number of Matches by Season** – Explores match counts across recorded seasons.
4. **World Cup Victories: Runs vs. Wickets** – Compares winning margins by runs and wickets.
5. **Distribution of World Cup Match Scores** – Analyzes score distribution and scoring patterns.
6. **Top 10 Teams by Average Recorded Score** – Ranks teams by their average recorded scores.
7. **Top 10 Hosts by Recorded Match Count** – Compares host countries by recorded match totals.
8. **Relationship Between Team Scores** – Uses a scatter plot to explore scoring patterns between opposing teams.

## 🔍 Key Learnings

- Handling missing values and inconsistent data
- Exploratory Data Analysis (EDA)
- Grouping, aggregation, and ranking

- Extracting insights from sports data
