# Finance Data Analysis

An Excel-based finance data analysis project focused on data cleaning, analysis, financial calculations, Pivot Tables, and dashboard creation.

## Tools Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Data Visualization
- Dashboarding

## Project Objective

To analyze financial data, identify important trends and patterns, and generate meaningful business insights using Excel.

## Key Analysis

- Financial performance analysis
- Revenue and expense analysis
- Profitability analysis
- Trend analysis
- Category-wise analysis
- Pivot Table analysis
- Dashboard visualization
